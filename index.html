Top Viva Questions & Answers:

Q1: What is the difference between Terraform and Puppet?

Terraform is an Infrastructure as Code (IaC) tool used for provisioning bare cloud infrastructure (EC2, VPC, Firewalls). Puppet is a Configuration Management (CM) tool used for configuring packages, services, and files inside the operating system.

Q2: What is Idempotency in DevOps?

Idempotency guarantees that executing the automation code multiple times produces the exact same desired state without duplicate changes or failures. Puppet checks current state before making changes.

Q3: How is Configuration Drift prevented?

If an admin stops Apache or modifies configuration manually, Puppet agent detects the drift and automatically restores the system to the desired catalog state.
